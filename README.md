## 🎯 Objetivo

Este repositório reúne minhas soluções para os desafios de programação e banco de dados da plataforma **HackerRank**. O foco é praticar lógica de programação, estruturas de dados, orientação a objetos em **Java** e consultas relacionais em **SQL**.
